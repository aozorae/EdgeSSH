# 管理主机

通过所选方式验证管理员后，首页显示同一份主机资料。单管理员最多保存 200 台；切换 Cloudflare/GitHub 登录不会更改资料归属或清空主机。

## 新建主机

选择新增主机，填写：

| 字段 | 说明 |
| --- | --- |
| 名称 | 用于列表识别，例如“东京测试机” |
| 地址 | 公网域名或公网 IP，不带协议 |
| 端口 | SSH 端口，默认通常为 `22` |
| 用户名 | 目标服务器的 SSH 用户 |
| 分组 | 可选，用于筛选 |
| 认证方式 | 密码或未加密 OpenSSH 私钥 |
| 终端编码 | UTF-8、GB18030 或 Big5 |

保存地址时，Worker 会解析公网 IP 并尝试获取城市信息。定位失败不会阻止保存或连接；地球上的点位只表示记录位置，不表示服务器在线。

## 凭据更新规则

编辑主机时，凭据输入留空表示保留原值。切换认证方式时，应明确填写新方式所需凭据并保存。

主机列表接口不会返回密码或私钥。建立连接前，Worker 才会解密当前记录，并为一次性会话票据准备连接信息。

## 搜索与分组

使用搜索查找名称、地址或标签，并用分组筛选减少列表范围。地球视图和主机列表都是完整入口：点选地球标记或列表项都可以进入工作台。

## 刷新位置

服务器迁移或 DNS 指向变化后，可以从主机编辑界面刷新定位。刷新会重新解析公网地址并更新加密资料，不会检测服务器是否在线。

## 删除主机

删除操作只移除当前身份的这条加密记录，不会关闭服务器、删除服务器文件或修改 SSH 配置。若对应工作台仍在使用，先退出会话再删除记录。
