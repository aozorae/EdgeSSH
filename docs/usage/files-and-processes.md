# 文件与进程

终端旁的辅助面板通过独立 SSH 通道运行。它们与主终端共享当前受认证会话，但拥有各自的附着令牌和消息边界。

## SFTP 文件管理

当前实现基于 SFTP v3，支持：

- 浏览远端目录。
- 上传与下载单个文件。
- 新建目录。
- 重命名文件或目录。
- 删除文件。
- 删除空目录。

单文件上传上限为 2 GiB，下载上限为 64 MiB。上传按 64 KiB 分块，最多 512 KiB 在途，请保持页面和连接开启。超过上限的文件、目录递归传输或需要断点续传时，建议使用服务器已有工具；[Agent CLI](./agent-cli#大文件上传) 支持同样的上传上限。

::: warning 先用测试目录验收
首次部署后，在专门测试目录中完成上传、下载、重命名与删除。不要直接使用 `/etc`、应用数据目录或生产发布目录。
:::

## 进程面板

进程面板通过远端命令收集：

- CPU 使用情况。
- 系统负载。
- 内存与 Swap。
- 进程列表。

显示结果取决于远端系统提供的命令和输出格式。系统过于精简或权限受限时，部分指标可能不可用，但不应影响主终端。

## 系统识别

EdgeSSH 会读取远端系统信息，识别常见 Linux 发行版、版本与架构。探测只用于界面展示，不会安装软件或修改系统文件。

## 辅助面板故障

遇到面板无法加载时：

1. 先确认主终端仍可执行命令。
2. 检查 SSH 用户是否有权读取目标目录或进程信息。
3. 查看浏览器中的用户可读错误，不要上传包含凭据的完整网络记录。
4. 重新进入工作台，排除辅助通道的临时断开。
